PIXEL MUSIC 8BIT  —  像素风网易云播放器

怎么用
  1. 解压到任意可写目录（桌面 / 文档，不要放 C:\Program Files）
  2. 双击 PixelMusic.exe
  3. 等 3~5 秒，窗口出现

第一次用
  - 右上角点「未登录 / 昵称」→ 弹出二维码 → 用手机网易云 App 扫码
  - 登录后可点「我的歌单」；不登录也能搜歌听
  - 登录凭证只存在本机 .cookie.txt，不会上传，删除即退出登录

快捷键
  SPACE 播放/暂停    ← → 切歌    输入框回车搜索
  拖标题栏移动窗口   拖右下角三角改大小

注意事项
  - 需要 Windows 10/11 x64，系统自带 WebView2（Edge 一般已装）
  - 端口 8123 不能已被占用
  - 未签名程序，首次运行 Windows 可能提示「已保护你的电脑」→ 更多信息 → 仍要运行
  - 关闭窗口会同时结束后台服务
